# **App Name**: CampusConnect

## Core Features:

- Role-Based Dashboards: Customizable dashboards providing role-specific information and quick access to relevant tools for Director, Administrator, Teachers, Accounts staff, Students, Parents, Librarian, and Cook.
- Student Management: Comprehensive module to manage student profiles, enrollment, demographics, and related data.
- Academic Management: Tools to manage courses, classes, schedules, and academic calendars.
- Centralized Communication Hub: A communication system for announcements, direct messaging between users, and school-wide notifications.
- Attendance Tracking: System to record and manage student attendance records.
- Grade Tracking: Tools for teachers to input, manage, and report student grades.
- Intelligent Summaries of School Notices: An AI-powered tool to summarize school-wide announcements into concise points for quick review, tailored to the user's role (e.g., parents see summaries focused on events and deadlines, teachers see summaries focused on policy changes and meeting schedules).

## Style Guidelines:

- Primary color: Modern blue (#468B97) to convey trust, security, and professionalism.
- Background color: Light gray (#D3D3D3) for a clean, uncluttered interface.
- Accent color: Bright orange (#E2D784) for call-to-action buttons and highlighting important information.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, machined look that works for both headlines and body text.
- Use clear, simple icons from a consistent icon set to represent different modules and functions.
- A clean, responsive layout that adapts to different screen sizes and devices, ensuring accessibility for all users.
- Subtle transitions and animations to provide feedback on user interactions and enhance the user experience.
